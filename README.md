# Família em Missão

Aplicativo da família para tarefas, pontos, recompensas e cofrinho, com modo Responsável e modo Criança.

- **App:** `index.html` (arquivo único, sem etapa de build)
- **Funciona sem internet:** `sw.js`
- **Instalável no celular:** `manifest.webmanifest` e ícones
- **Sincronização entre aparelhos:** Supabase (o banco é preparado uma vez pelo arquivo `supabase.sql`, que não fica neste repositório)

Publicado pela Vercel: cada mudança neste repositório atualiza o site automaticamente.
